# Шаг 2. Приложение на телевизор Samsung

🇬🇧 [English](en/install-tv.md)

Samsung не даёт ставить на телевизор приложения не из своего магазина просто так. Поэтому
приложение устанавливается как у разработчика: телевизор переводится в режим разработчика,
приложение подписывается вашим личным сертификатом Samsung (бесплатно) и отправляется на телевизор
с компьютера. Делается один раз, дальше плеер живёт на телевизоре как обычное приложение.

Перед этим шагом должен работать аддон — [install-ha-addons.md](install-ha-addons.md).

Подпись и отправку на телевизор делает **программа-установщик** — это простой способ, минут 10.
Ниже него — ручной способ через Tizen Studio (около часа), он нужен, если вы меняете код плеера.

## Простой способ: AssisTV Installer (Windows)

Понадобятся: компьютер с Windows в той же домашней сети, что и телевизор; учётная запись Samsung
(та же, что на телевизоре, или любая другая — бесплатно) — только для телевизоров с 2023 года.

1. **Скачайте** [AssisTV-Installer.exe](https://github.com/indoor25/AssisTV/releases/latest/download/AssisTV-Installer.exe)
   (страница всех версий — [Releases](https://github.com/indoor25/AssisTV/releases)) и запустите.
   Windows может предупредить, что программа незнакома: **«Подробнее» → «Выполнить в любом случае»**
   (у программы нет платной подписи издателя). Откроется окно-терминал и страница в браузере —
   окно не закрывайте, пока идёт установка.
2. **Выберите телевизор.** Включённые телевизоры Samsung в сети находятся сами. Нет в списке —
   впишите IP телевизора (на TV: Настройки → Сеть → Состояние сети → Настройки IP).
3. **Включите режим разработчика** — страница покажет шаги и **точный адрес**, который надо вписать:
   на телевизоре **Приложения** (Apps) → на пульте **1 2 3 4 5** → **Developer mode — On**,
   **Host PC IP** — адрес со страницы → **OK** → удерживайте кнопку питания 5 секунд (перезагрузка).
   Страница сама увидит, что телевизор готов, и пойдёт дальше.
4. **Выберите, что ставить:** «AssisTV» — последняя версия с GitHub. Здесь же можно поставить
   свой файл `.wgt` или приложение из другого репозитория GitHub (`владелец/репозиторий`).
5. **«Установить на телевизор».** Телевизор с 2023 года (Tizen 7 и новее) попросит один раз **войти в Samsung**:
   откроется страница Samsung, после входа установщик сам получит сертификат для вашего телевизора и продолжит.
   Пароль вводится только на странице Samsung. Телевизорам постарше вход не нужен.
6. **«Установлено»** → «Открыть на телевизоре» → дальше [первый запуск](#27-первый-запуск).
   Кнопка **«Закрыть установщик»** завершает программу.

**Обновление** — то же самое: запустить установщик, выбрать телевизор и «AssisTV». Настройки плеера
сохраняются. Сертификаты установщик хранит в `%APPDATA%\AssisTV-Installer` — **эту папку не удаляйте**:
обновить приложение поверх можно только тем же сертификатом, с новым его придётся сначала удалить,
и настройки на телевизоре пропадут.

| Что видно | Что сделать |
|-----------|-------------|
| Телевизор не находится | он выключен или в другой сети (гостевой Wi-Fi); впишите IP вручную |
| «Телевизор не принимает подключение» | режим разработчика выключен или телевизор не перезагрузили после включения |
| «Телевизор сбросил подключение» | в Host PC IP вписан не тот адрес — впишите адрес со страницы и перезагрузите TV |
| После входа в Samsung страница не идёт дальше | скопируйте всё, что показала страница Samsung, и вставьте в поле в окне установщика |
| «Приложение уже стоит и поставлено кем-то другим» | его ставили другим сертификатом (например, через Tizen Studio); «Удалить и поставить заново» — настройки приложения пропадут |
| «Телевизор не принял пакет» | ниже показан ответ телевизора; для чужих приложений — сообщите его автору |

Установщик открывает только страницу на вашем компьютере (127.0.0.1) и ничего не слушает из сети.
Его исходный код — папка [`installer/`](../installer/README.ru.md).

## Ручной способ: Tizen Studio

## 2.1. Скачайте проект

На странице репозитория на GitHub: **Code → Download ZIP** и распакуйте, например, в `C:\AssisTV`.
(Или `git clone https://github.com/indoor25/AssisTV.git C:\AssisTV`.)

> Путь лучше без пробелов и русских букв — с ними инструменты Tizen иногда ломаются.

## 2.2. Установите Tizen Studio

1. Скачайте **Tizen Studio** (установщик «with IDE») с сайта
   [developer.tizen.org](https://developer.tizen.org/development/tizen-studio/download) и установите
   (по умолчанию в `C:\tizen-studio`).
2. В конце установки откроется **Package Manager** (или запустите его из меню «Пуск»):
   - вкладка **Main SDK** — установите **Tizen SDK tools**;
   - вкладка **Extension SDK** — установите **Samsung Certificate Extension** и **TV Extensions**
     (или «Samsung TV Extension»; версия любая, лучше последняя).

## 2.3. Включите режим разработчика на телевизоре

1. Узнайте IP-адрес **компьютера**: Windows — `ipconfig` в командной строке, строка «IPv4-адрес».
2. На телевизоре откройте **Приложения** (Apps) и наберите на пульте **1 2 3 4 5**
   (на пульте без цифр — кнопка «123» или «⋯» покажет цифры на экране).
3. В появившемся окне: **Developer mode — On**, **Host PC IP** — IP компьютера → **OK**.
4. **Перезагрузите телевизор**: выключите и включите (на некоторых моделях — удерживать кнопку питания,
   пока не появится логотип Samsung). Вверху экрана «Приложения» появится надпись **Developer Mode**.

## 2.4. Подключите телевизор к Tizen Studio

1. Запустите Tizen Studio → меню **Tools → Device Manager**.
2. **Remote Device Manager** → **+** → Name — любое, IP — адрес телевизора, Port — `26101` → **Add**.
3. Переключите **Connection** в положение **On**. Телевизор появится в списке устройств.

## 2.5. Создайте сертификат

1. Tizen Studio → **Tools → Certificate Manager** → **+**.
2. Тип — **Samsung**, устройство — **TV**.
3. **Certificate profile name** — придумайте, например `mytv`. Запомните это имя.
4. **Create a new author certificate**: имя, пароль (запомните) → войдите в **учётную запись Samsung**
   (если её нет — там же можно создать).
5. **Distributor certificate**: Privilege level — **Public**. В списке **DUID** уже будет DUID
   подключённого телевизора (если нет — добавьте вручную: он виден в Device Manager).
   Если телевизоров несколько, подключите их все (шаг 2.4) и добавьте все DUID сюда же.
6. **Finish**.

> Новый телевизор позже — его DUID нужно добавить в сертификат (Certificate Manager → профиль →
> пересоздать distributor certificate со всеми DUID), иначе установка на него не пройдёт.

## 2.6. Соберите и установите приложение

Откройте **PowerShell** (Windows) и выполните, подставив свои значения
(`C:\AssisTV` — папка проекта, `192.168.1.20` — IP телевизора, `mytv` — имя профиля сертификата):

```powershell
cd C:\AssisTV
.\tools\build-wgt.ps1 -Cert mytv -Install 192.168.1.20:26101
```

Скрипт собирает пакет из чистой копии (в него идут только файлы плеера), подключается к телевизору
(`sdb connect`), ставит пакет и отключается. Без `-Install` — только собирает
`.buildResult\AssisTV.wgt`. Tizen Studio он ищет в `C:\tizen-studio`.

- При сборке может спросить пароль сертификата — это пароль из шага 2.5.
- Не подключается — проверьте, что в режиме разработчика на TV стоит IP этого компьютера.
- Успешная установка заканчивается строкой `Installed the package: Id(TzIptvPl01)` или похожей.

**Телевизор 2017–2020 года** (Tizen 3–5.5; год видно по модели: …M… — 2017, …N… — 2018, …R… — 2019,
…T… — 2020): добавьте **`-Legacy`** — скрипт переведёт код под старый браузер телевизора и соберёт
`.buildResult\AssisTV-legacy.wgt`. Для этого нужен [Node.js](https://nodejs.org) (один раз
`npm install` в папке `tools\legacy`):

```powershell
cd C:\AssisTV\tools\legacy; npm install; cd C:\AssisTV
.\tools\build-wgt.ps1 -Cert mytv -Legacy -Install 192.168.1.20:26101
```

Обычная сборка на таком телевизоре просто не ставится (ошибка про версию платформы).

На macOS/Linux скрипт работает в PowerShell 7 (`pwsh`), если Tizen Studio в PATH
(`~/tizen-studio/tools/ide/bin` и `~/tizen-studio/tools`).

## 2.7. Первый запуск

1. На телевизоре откройте **Приложения** — там появится **AssisTV**. Запустите. Откроется **мастер настройки**
   (кнопки — ▲▼ выбор, ◄► переключатель, OK — нажать, RETURN — назад).
2. **Шаг 1 — язык.** ◄► — язык интерфейса («Как у телевизора» или один из четырёх), OK на **«Далее»**.
3. **Шаг 2 — адрес аддона.** OK на поле — появится клавиатура. Введите `<IP HA>:8765`
   (например, `192.168.1.10:8765`), закройте клавиатуру, OK на **«Далее»**. Плеер сразу проверит адрес;
   если аддон не отвечает, ошибка будет под полем.
4. **Шаг 3 — привязка.** Телевизор покажет **код из 6 цифр**. В Home Assistant откройте пункт **AssisTV**
   в боковом меню → раздел **«Привязка телевизора»**: там заявка с тем же кодом — нажмите **«Привязать»**.
   Привязка нужна один раз: так чужое устройство в сети не получит ваши плейлисты и управление.
   Ошиблись адресом — OK на экране кода вернёт к шагу 2.
5. **Готово.** Телевизор сам загрузит плейлист и включит первый канал; на экране — главное о кнопках пульта.
   OK на **«Смотреть»**.

Язык и адрес потом меняются в Настройках (главный экран → вверху **Настройки**).

На странице AssisTV в Home Assistant задайте телевизору название, remote и media_player и комнату
(см. [install-ha-addons.md](install-ha-addons.md), шаг 1.5).

Поле **MQTT** в настройках оставьте пустым: команды из Home Assistant телевизор получает через аддон,
со своим токеном. Своё подключение к брокеру (хост, порт `1884`, логин) вписывают, только если
хочется обойтись без аддона в этой цепочке.

Как пользоваться — [usage.md](usage.md).

## Обновление приложения

Скачайте новую версию проекта в ту же папку и повторите команду из шага 2.6. Настройки, порядок каналов, логотипы и места просмотра фильмов
сохраняются.

- Установка закрывает запущенный плеер — обновляйте, когда телевизор никто не смотрит.
- Проверить, что обновилось: на телевизоре Настройки → «Этот телевизор» → **«Версия плеера»**.
- Новые источники фильмов переустановки **не требуют**: это плагины, телевизор скачивает их у аддона
  сам ([vod-plugins.md](vod-plugins.md)).

## Если что-то не так

| Что видно | Что сделать |
|-----------|-------------|
| `sdb connect` — `failed to connect` | режим разработчика выключен или в нём указан не тот IP компьютера; телевизор не перезагружали после включения режима |
| `install` — ошибка про сертификат / `author signature` | DUID телевизора нет в сертификате (шаг 2.5) или пакет подписан другим профилем |
| `install` — `Failed to install Tizen application` без подробностей | путь к проекту с пробелами или русскими буквами — перенесите в `C:\AssisTV` |
| Чёрный экран с красной надписью | это ошибка старта, текст в надписи; частая причина — неверный адрес аддона |
| Каналы есть, но карточка и голос не видят телевизор | проверьте порт 1884 у Mosquitto (шаг 1.1) и поле MQTT в настройках (выше) |
| Код привязки на экране, а заявки в HA нет | обновите страницу AssisTV; адрес аддона в Настройках должен вести на этот Home Assistant |
| В окне плейлистов «не загрузился — проверьте ссылку в аддоне» | ссылка на плейлист в настройках аддона неверная или истекла — подробности в `/status` (поле `lastError`) |
| Надпись «Аддон недоступен» | Home Assistant выключен или адрес аддона неверный; плеер работает со старыми каналами и проверяет раз в минуту |

`sdb shell` и `sdb dlog` на телевизорах Samsung обычно не работают — это ограничение прошивки, а не ошибка настройки.

## Для разработчиков

- Приложение — обычное Tizen Web App: HTML/CSS/JS без сборщиков, видео через `webapis.avplay`.
- В `config.xml` `package` — ровно 10 символов (`TzIptvPl01`), `<name>` — без пробелов (`AssisTV`);
  нарушение любого из этих правил ломает установку без понятной ошибки.
- Свои адреса по умолчанию (несколько телевизоров — не вводить на каждом): файл с
  `window.LOCAL_DEFAULTS = { addonUrl: 'http://<IP HA>:8765' }` (пример — `js/local-defaults.js`) и
  сборка `.\tools\build-wgt.ps1 -Cert mytv -Defaults <файл>`. Тогда мастер не открывается — телевизор сразу показывает код привязки.
- `tizen run -p TzIptvPl01.IPTVTizen -s <IP TV>:26101` запускает приложение с компьютера.
