# Аддон Home Assistant

```
ha-addon/
├── epg_builder/     — аддон «AssisTV»: плейлисты, EPG, реестр телевизоров,
│                      карточка IPTV, родительский контроль, поиск фильмов, запросы для голоса
└── deploy.ps1       — установка и обновление аддона на сервер HA одной командой (по SSH)
```

Инструкции:

- установка — [../docs/install-ha-addons.md](../docs/install-ha-addons.md);
- все настройки — [../docs/addon-iptv.md](../docs/addon-iptv.md);
- голос и чат — [../docs/assist.md](../docs/assist.md).

English: [install](../docs/en/install-ha-addons.md), [all options](../docs/en/addon-iptv.md), [voice and chat](../docs/en/assist.md).

Короткая справка, которая видна на вкладке «Документация» аддона в Home Assistant, — `epg_builder/DOCS.md`.
Файл `repository.yaml` для магазина приложений лежит в корне репозитория.

> **Про `epg_builder/shared/`.** Там копии общих файлов из `js/` и `lang/` плеера (парсеры, поиск
> каналов, реестр и плагины источников фильмов, переводы): каналы на сервере и на
> телевизоре должны сопоставляться одинаково, поэтому логика не дублируется, а файлы копируются.
> `deploy.ps1` делает это сам; после правок в `js/` запустите его (или скопируйте файлы руками)
> и закоммитьте обновлённый `shared/` — из него собирается аддон при установке из магазина.
