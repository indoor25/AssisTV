# AssisTV Installer

🇬🇧 [English](README.md)

Ставит AssisTV — или любой другой `.wgt` — на телевизор Samsung (Tizen) **без Tizen Studio**, сертификатов
и командной строки. Одна программа, одна страница в браузере.

> **Состояние: ранняя версия.** Проверено на настоящем телевизоре Samsung с Tizen 10 (вход → сертификат →
> установка). Телевизоры постарше (Tizen 3–6) ещё не проверены — см. «Что проверено».

## Что делает человек

1. Запускает `AssisTV-Installer.exe`. В браузере открывается страница.
2. Выбирает свой телевизор из списка (он находится сам).
3. Включает на телевизоре **режим разработчика** — страница показывает четыре шага и точный адрес,
   который нужно вписать, и сама идёт дальше, когда телевизор готов.
4. Выбирает, что ставить: AssisTV (последний релиз), свой файл `.wgt` или репозиторий GitHub.
5. Телевизоры с 2023 года (Tizen 7 и новее): один раз входит в учётную запись Samsung. Сертификат
   для телевизора программа делает сама.

Всё остальное — подпись пакета, отправка на телевизор, запуск приложения — делает программа.

## Как это устроено

| Шаг | Как |
| --- | --- |
| Найти телевизор | опрос всех адресов домашней сети: `http://<tv>:8001/api/v2/` |
| Связь с телевизором | свой небольшой клиент sdb (`src/sdb.js`), TCP-порт 26101 |
| Tizen 7 и новее | сертификат Samsung, привязанный к DUID телевизора (`src/certs.js`); вход Samsung возвращает на `localhost:4794` |
| Телевизоры старее | уже подписанный пакет ставится как есть; иначе подписывается сертификатом Tizen, сделанным на месте, — без входа |
| Установка | пакет кладётся в `/home/owner/share/tmp/sdk_tools/` и ставится командой `vd_appinstall` |

Программа слушает только `127.0.0.1`. Сертификаты лежат в `%APPDATA%\AssisTV-Installer`.
**Эту папку нужно сохранить**: приложение обновляется поверх, только пока автор подписи тот же; с новым
автором его придётся сначала удалить, и настройки приложения на телевизоре пропадут.

Пароль Samsung вводится на странице самой Samsung; программа получает только ключ доступа, который Samsung
присылает в ответ, и использует его один раз — чтобы запросить сертификат.

## Запуск из исходников и сборка

```
cd installer
npm install
npm start            # запустить
npm test             # самопроверка на поддельном телевизоре
.\build.ps1          # → dist\AssisTV-Installer.exe (нужен Node.js 25.5+)
```

`node test/fake-tv.js 6.5` — поддельный телевизор на `127.0.0.1`, чтобы посмотреть страницу без настоящего.
Вместо адреса можно ввести `ip:порт`, если порт sdb нестандартный.

## Что проверено

- Клиент sdb, отправка файла, разбор пакета, отказы телевизора и неисправные пакеты — на поддельном
  телевизоре (`npm test`).
- Настоящий телевизор с Tizen 10 (2026 год): поиск, проверка режима разработчика, вход в Samsung →
  сертификат, подпись, установка, запуск.
- Подпись сертификатом Tizen (телевизоры старше Tizen 7): хеши и структура совпадают с пакетом, подписанным
  Tizen Studio, который принимает телевизор на Tizen 3.
- **Ещё нет**: установка на настоящий телевизор старше Tizen 7.

Windows показывает предупреждение SmartScreen: у `.exe` нет подписи издателя
(«Подробнее» → «Выполнить в любом случае»).
