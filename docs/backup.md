# Обновление и резервные копии

🇬🇧 [English](en/backup.md)

## Как обновить

**Аддон.**
- Установлен из магазина приложений (способ А) — Home Assistant сам покажет обновление в
  Настройки → Приложения → AssisTV → **Обновить**.
- Скопирован папкой (способ Б) — скачайте новую версию проекта, замените папку `addons/epg_builder`
  через Samba, затем Настройки → Приложения → Установить приложения → ⋮ → «Проверить наличие
  обновлений» → AssisTV → **Обновить** (если версия поднялась) или ⋮ → **Пересобрать**.
- Из исходников (способ В) — `.\ha-addon\deploy.ps1 -PiHost <IP HA>`.

Настройки аддона и его данные (телевизоры, ручные сопоставления каналов, PIN, избранное, напоминания,
список просмотренного) при обновлении сохраняются.
После обновления аддона обновите страницу Home Assistant, чтобы подтянулась новая карточка.

**Скрипты для голоса.** Если в новой версии изменился `ha-config/iptv-assist-scripts.yaml`, замените
им свои скрипты IPTV в `scripts.yaml` (см. [assist.md](assist.md), шаг 4.2) и перезагрузите скрипты.
Появились новые скрипты — откройте им доступ для Assist (шаг 4.3), иначе ИИ их не увидит.

**Приложение на телевизоре.** Повторите команды из [install-tv.md](install-tv.md), шаг 2.6.
Настройки, порядок каналов, логотипы и места просмотра фильмов сохраняются.

**Какая версия стоит.** Аддон — номер вверху его страницы в «Приложениях». Плеер — на телевизоре:
Настройки → «Этот телевизор» → «Версия плеера»; или с компьютера в браузере:
`http://<IP телевизора>:8001/api/v2/applications/TzIptvPl01.IPTVTizen` (поле `version`).

## Резервные копии

Всё, что плеер хранит в Home Assistant (телевизоры, сопоставления каналов, PIN, избранное,
напоминания, список просмотренного, настройки аддона, скрипты, карточки), попадает в обычную резервную копию Home Assistant:
**Настройки → Система → Резервные копии**. Там же — автоматическое расписание (например, каждую ночь,
хранить 3–7 копий) и хранение в облаке (Home Assistant Cloud, Google Drive и др.).

Настройки на самом телевизоре (адрес аддона, порядок каналов, свои логотипы, места, где остановились
в фильмах) хранятся только в нём.
При переустановке приложения они сохраняются, при сбросе телевизора — нет.

## Восстановление с нуля

1. Установите Home Assistant и восстановите резервную копию — аддон, его данные и скрипты вернутся.
   Если копии нет — пройдите [шаг 1](install-ha-addons.md), [шаг 3](ha-dashboards.md) и [шаг 4](assist.md) заново.
2. Телевизоры узнают аддон сами. Если у Home Assistant поменялся IP-адрес — поменяйте адрес аддона
   в настройках плеера на каждом телевизоре.

## Для тех, кто правит код

- Секретов в репозитории нет: плейлист с токеном и ключ портала — в настройках аддона,
  пароль MQTT телевизор получает от аддона. Свои настоящие значения храните вне git
  (папка `private/` и файл `sample-playlist.m3u8` уже в `.gitignore`).
- Перед коммитом полезно проверить, что секрет не попал в индекс: `git grep --cached -F -- '<значение>'`.
- `.gitignore` не понимает комментарии в конце строки — только на отдельной строке.
