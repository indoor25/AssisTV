# Аддон «AssisTV»: все настройки

🇬🇧 [English](en/addon-iptv.md)

Аддон — сервер для телевизоров: качает плейлисты и EPG, сопоставляет каналы с программой,
проверяет архив, ищет фильмы в источниках, добавляет рейтинги и рецензии, хранит избранное,
напоминания и реестр телевизоров, отдаёт карточку для Home Assistant, держит родительский контроль
и отвечает на запросы голосового помощника.

**Зачем он нужен.** Источник EPG (`epg.it999.ru/epg.xml.gz`) — 42 МБ в gzip и 386 МБ XML.
Телевизор такой файл не разбирает и падает по памяти. Аддон делает это на сервере Home Assistant и отдаёт телевизору
компактный JSON: только каналы плейлиста и нужное окно времени.

Установка — [install-ha-addons.md](install-ha-addons.md). Приложение на TV — [install-tv.md](install-tv.md).
Карточка — [ha-dashboards.md](ha-dashboards.md). Голос и чат — [assist.md](assist.md).

## Опции аддона

| Параметр        | По умолчанию                      | Что это |
|-----------------|-----------------------------------|---------|
| `playlists`     | пример                            | список `{name, url}` M3U-плейлистов с каналами. Источники фильмов настраиваются в разделе «Плагины» на странице аддона ([vod-plugins.md](vod-plugins.md)); старые строки `<тип>::[параметры]<адрес>` переносятся туда сами |
| `epg_urls`      | `https://epg.it999.ru/epg.xml.gz` | один или несколько XMLTV (`.xml` или `.xml.gz`); при конфликте выигрывает тот, что выше |
| `past_hours`    | `3`                               | сколько часов прошедших передач держать в плейлисте для TV |
| `future_hours`  | `36`                              | на сколько часов вперёд |
| `refresh_hours` | `6`                               | как часто пересобирать |
| `manual_map`    | пусто                             | ручное сопоставление каналов (удобнее делать в окне на странице аддона) |
| `mqtt_ws_port`  | `1884`                            | WebSocket-порт Mosquitto, который аддон сообщает телевизорам |
| `language`      | `auto`                            | язык страницы аддона и ответов для голоса и чата: `auto` (язык Home Assistant), `en`, `ru`, `uk`, `de` |
| `tmdb_key`      | пусто                             | ключ TMDB: рейтинг, жанры, описание фильмов (см. ниже) |
| `kinopoisk_key` | пусто                             | ключ Кинопоиска: его оценка и рецензии зрителей (см. ниже) |

**Свои ссылки подставьте в опциях** — в репозитории вместо них `example.com`:
плейлист провайдера (обычно с личным токеном).
После изменения опций нажмите «Сохранить» и перезапустите аддон.

Про размер: окно −3ч..+36ч — это около 40 тыс. передач, 2,7 МБ JSON (0,6 МБ в gzip).
`future_hours: 168` (неделя) увеличит файл в 4–5 раз. Для поиска передач и напоминаний аддон и так
держит у себя программу на неделю вперёд — увеличивать `future_hours` ради этого не нужно.

Пример раздела `playlists` (вкладка «Конфигурация» → ⋮ → «Редактировать в YAML»):

```yaml
playlists:
  - name: Телевидение
    url: http://example.com/playlists/uplist/ВАШ_ТОКЕН/playlist.m3u8
epg_urls:
  - https://epg.it999.ru/epg.xml.gz
tmdb_key: 0123456789abcdef0123456789abcdef
kinopoisk_key: 01234567-89ab-cdef-0123-456789abcdef
```

### Рейтинги и рецензии

Сами источники фильмов рейтингов не дают — аддон берёт их по названию и году из двух каталогов.
Оба ключа бесплатные и необязательные; можно задать один, оба или ни одного.

| Ключ | Что даёт | Где взять |
|------|----------|-----------|
| `tmdb_key` | рейтинг TMDB, жанры, описание на языке аддона | [themoviedb.org](https://www.themoviedb.org) → регистрация → Настройки → API → **API Key (v3 auth)** — 32 символа (не длинный v4-токен). В поле «сайт» в анкете можно вписать что угодно |
| `kinopoisk_key` | оценка Кинопоиска, **рецензии зрителей на русском**, русские жанры | [kinopoiskapiunofficial.tech](https://kinopoiskapiunofficial.tech) → регистрация → ключ сразу в личном кабинете. Лимит — 500 запросов в сутки, остаток виден в `/status` (поле `kinopoisk`) |

Зачем оба: у советского и русского кино на TMDB почти нет голосов («Иван Васильевич меняет профессию»
— 8,8 на Кинопоиске против 7,9), а мировой каталог у TMDB шире. В карточке фильма видны обе оценки.

- Совпадение ищется по названию и году; сомнительное отбрасывается — лучше без рейтинга, чем с чужим
  (ремейки: «Дюна» 1984 и 2021 — разные фильмы).
- Рейтинг меньше чем по 10 голосам не показывается.
- Найденное хранится 30 дней, поэтому запросов уходит мало.
- Рейтинги вдруг пропали — откройте `http://<IP HA>:8765/status`: скорее всего, кончилась дневная квота.

## Страница аддона

Включите у аддона **«Показывать на боковой панели»** — в меню HA появится пункт с его страницей
(она же доступна на `http://<IP HA>:8765/`). Там:

- **Привязка телевизора**: заявки новых телевизоров с кодом из 6 цифр — «Привязать» или «Отклонить».
  У каждого привязанного TV — «Сбросить привязку» (ему придётся привязаться заново).
- **Плагины**: источники фильмов — установка по ссылке или файлом, настройки, «Включён»,
  «Работать на телевизоре без аддона», удаление ([vod-plugins.md](vod-plugins.md)).
- **Телевизоры**: имя каждого TV, сущности `remote.*` и `media_player.*` для включения питания
  и запуска приложения, MQTT-топики, YAML карточки, кнопка «Удалить телевизор».
  Телевизор появляется в списке сам, когда приложение на нём первый раз запустится.
  Область прибора задаётся в HA (Настройки → Устройства), имя — здесь.
- **Плейлисты**: что сейчас загружено, когда собиралось.
- **«+ Сопоставить канал»**: слева каналы плейлиста, справа каналы EPG (с числом передач и датой
  последней). Кнопки «Присвоить», «Без программы», «Вернуть автоматическую». Привязки хранятся
  в `/data/manual_map.json` и важнее опции `manual_map`. После привязки аддон пересобирает
  плейлисты за пару секунд, без полной загрузки EPG.
- **Родительский контроль**: PIN и группы (см. ниже). **Менять настройки можно только через
  боковую панель HA** (ingress): напрямую по `http://<IP HA>:8765` страница работает
  в режиме просмотра.

## Адреса сервиса

Кто может открыть адрес: **все** — любой в домашней сети; **TV** — привязанный телевизор (с токеном,
см. [install-tv.md](install-tv.md), «Первый запуск»); **HA** — только через боковую панель Home Assistant (ingress). Через панель HA
открываются и адреса «TV», поэтому проверять из браузера удобнее там. Другие аддоны (сеть hassio) видят
`/tvs.json` и полный `/status`.

| Адрес | Кто | Назначение |
|-------|-----|------------|
| `/` | все | страница аддона; напрямую по `:8765` — только подсказка, настройки — в панели HA |
| `/status` | все | состояние сборки: время, размер, сколько каналов совпало, несовпавшие, последняя ошибка, источники фильмов (`vod_sources`), квота Кинопоиска; напрямую — краткий |
| `POST /tvs/register` | все | регистрация телевизора; незнакомому — код привязки |
| `/posters/<id>.jpg` | все | постеры (кеш аддона) |
| `/playlists.json` | TV | список плейлистов для телевизора |
| `/playlists/<id>.json` | TV | каналы + EPG одного M3U |
| `/playlists/<id>/archive.json?name=` | TV | программа за прошлые дни для архива |
| `/playlists/<id>/programme.json?name=&at=` | TV | описание передачи (жанр, возраст, текст) |
| `POST /vod/call` | TV | вызов метода плагина-источника фильмов (`{playlist, method, args}`) |
| `/vod/search?q=матрица` | TV | поиск фильма; `&src=<тип>` — в одном источнике |
| `/vod/meta?title=&year=&kind=` | TV | рейтинг, жанры, описание |
| `/vod/reviews?id=<id Кинопоиска>&page=1` | TV | рецензии |
| `/favorites.json`, `POST /favorites` | TV | избранное |
| `/vod-sources.json`, `/vod-sources/<тип>.js` | TV | копии плагинов, отмеченных «без аддона» |
| `POST /parental/check` | TV | проверка PIN родительского контроля |
| `WS /mqtt` | TV | MQTT телевизора через аддон: логин — tv_id, пароль — токен; только свои топики |
| `/tvs.json`, `/tvs/…` | HA | реестр телевизоров, имя, сущности питания, удаление |
| `/pairing/…` | HA | привязка по коду, сброс привязки |
| `/plugins/…` | HA | установка, настройки и удаление плагинов |
| `/mapping…` | HA | ручное сопоставление каналов с программой |
| `/parental/pin`, `/parental/off`, `/parental/groups` | HA | родительский контроль |
| `/rebuild` | HA | пересобрать сейчас (`?force=1` — принять EPG, даже если он выглядит урезанным) |

**Защита от урезанного EPG.** Источники иногда отдают обрезанный файл (программа кончается через пару
часов). Если у свежего EPG программа дальше чем на 6 часов вперёд есть у заметно меньшего числа каналов,
чем у прежнего, аддон оставляет прежний и скачивает заново через 30 минут. В журнале — «EPG урезан…»,
в `/status` — `epgRejected`.

Если EPG ещё ни разу не собрался, данные отдаются с ошибкой 503; последняя удачная сборка лежит
в `/data`, поэтому после перезапуска телевизор получает её сразу.

## Родительский контроль

Задаётся на странице аддона (только через боковую панель HA):

- **PIN** — хранится хешем, восстановить нельзя, но можно задать новый без старого (защита —
  сам вход в HA).
- **Группы под замком** — по умолчанию определяются по названию (`взросл`, `adult`, `xxx`, `18+`).
- **Для каждого телевизора**: «показывать с замком» или «не показывать совсем».
- Открытый доступ действует **до выключения телевизора**.
- **Голосом защищённые каналы не включаются никогда.**
- В карточке защищённые группы тоже спрашивают PIN (до перезагрузки страницы).

После 5 неверных попыток — минута паузы (отдельно на телевизоре и в карточке).

## Управление из автоматизаций и голосом

Для голоса и чата есть готовые скрипты — [assist.md](assist.md). Ниже — то, на чём они построены;
пригодится для своих автоматизаций.

Аддон слушает общий MQTT-топик `iptv/request` (JSON) и сам решает, на какой телевизор отправить команду:

```jsonc
{"request_id":"1","action":"channel","query":"первый канал","tv":"в нашей спальне"}
{"request_id":"2","action":"vod_search","query":"матрица"}
{"request_id":"3","action":"vod_play","query":"игра престолов 3 сезон","tv":"гостиная"}
{"request_id":"4","action":"status"}
{"request_id":"5","action":"command","command":"volume_down","value":3}
{"request_id":"6","action":"vod_play","query":"интерстеллар","quality":"4K"}
{"request_id":"7","action":"vod_info","query":"дюна 2021"}
{"request_id":"8","action":"favorite_add","query":"интерстеллар"}
{"request_id":"9","action":"vod_recommend","titles":"Пленницы (2013); Остров проклятых (2010)","tv":"гостиная"}
{"request_id":"10","action":"vod_play","choice":2}
{"request_id":"11","action":"guide_search","query":"футбол","day":"today"}
{"request_id":"12","action":"command","command":"sleep","value":30}
```

| `action` | Что делает | Поля |
|----------|-----------|------|
| `channel` | включить канал по названию (ошибки распознавания исправляются) | `query`, `tv` |
| `vod_search` | найти фильм во всех источниках, телевизор не нужен | `query`, `limit` |
| `vod_play` | найти и включить фильм/сериал (сериал — с последней серии и места) | `query` или `id`, `episode_fid`, `from_start`, `quality` («4K», «1080p», «best»), `choice` (номер из подборки на экране), `tv` |
| `vod_info` | рейтинг Кинопоиска и TMDB, жанры, описание, `available` — есть ли у источников | `query` |
| `favorites` | список избранного (полные записи) | — |
| `favorite` | добавить/убрать по `id` (`add: true/false`, без него — переключить) | `id`, `title`, `year`… |
| `favorite_add` | добавить голосом: без `query` — то, что идёт на телевизоре; подходят несколько — `error: ambiguous` и `options`, список показывается и на экране | `query`, `choice`, `tv` |
| `favorites_titles` | избранное названиями + `watched` (что смотрели) + `suggested_recently` | — |
| `vod_recommend` | показать на телевизоре подборку: аддон оставляет названия, которые есть у источников, не в избранном и не просмотрены | `titles` (строка через `;` или список), `more`, `tv` |
| `status` | что идёт (без `tv` — на всех, где плеер запущен) | `tv` |
| `guide` | программа канала на сутки (без `query` — канал, который идёт) | `query`, `tv` |
| `guide_search` | поиск передачи по всем каналам на неделю вперёд | `query`, `channel`, `day` |
| `remind` / `reminders` / `remind_cancel` | напоминание о передаче за 5 минут до начала | `ref` (из `guide_search`) или `query` |
| `tonight` | что будет вечером на каналах, которые в доме смотрят (аддон сам считает время просмотра каналов) | `day`, `from`, `to` (час или `ЧЧ:ММ`) |
| `move` | продолжить то, что идёт, на другом телевизоре с того же места; первый телевизор выключается | `to`, `from`, `keep` |
| `archive_guide` / `archive` | список передач канала из архива / включить запись | `query`, `start`, `tv` |
| `command` | `play`, `pause`, `play_pause`, `stop`, `next`, `prev`, `volume_up`/`volume_down` (шаг в `value`), `volume` (`value` 0–100), `mute`, `unmute`, `mute_toggle`, `open` (включить TV и плеер), `power_off` (выключить TV), `from_start` (передача или фильм с начала), `live` (в прямой эфир), `seek` (`value` секунд, минус — назад), `sleep` (`value` минут, 0 — отмена) | `command`, `value`, `tv` |

- `tv` — `tv_id`, название телевизора или пространство (комната) в HA; падежи учитываются
  («в нашей спальне» = «Спальня Наша»). Без `tv`: единственный телевизор или тот, где плеер запущен,
  если такой один; иначе ответ `ambiguous_tv` / `no_tv_on` со списком `tvs`.
- Для `channel` и `vod_play` выключенный телевизор включается (`KEY_POWER` через `remote.*`),
  плеер запускается, аддон ждёт его в сети (до ~1 мин).
- Ответ — в `iptv/request/result`: `{request_id, action, ok, message, error?, …}`. `message` — готовая
  фраза на языке аддона. Ошибки: `not_found`, `ambiguous_tv`, `tv_not_found`, `no_tv_on`, `player_off`,
  `locked` (родительский контроль), `timeout`, `unknown_command`, `ambiguous` (несколько фильмов —
  выберите `choice`), `no_movie`, `no_titles`, `none_available`, `no_archive`, `no_epg`.
- **Что считается просмотренным.** Аддон следит за состоянием плееров: фильм или сериал, который шёл
  10 минут, записывается в `/data/watched.json` и в подборки больше не попадает. `more: true` у
  `vod_recommend` дополнительно убирает всё, что показывали за последние 6 часов.
- За 5 минут до передачи с напоминанием аддон шлёт плашку на телевизоры (`iptv/<tv_id>/notify`) и
  событие `iptv/reminder` — на него можно повесить голос ([assist.md](assist.md)).
- Последний ответ также виден в датчике `sensor.iptv_otvet` (устройство «IPTV аддон»): состояние —
  `message`, атрибуты — весь ответ.

Пример автоматизации — в 7 утра на кухне включить новости:

```yaml
actions:
  - action: mqtt.publish
    data:
      topic: iptv/request
      payload: '{"action": "channel", "query": "Россия 24", "tv": "кухня"}'
```

Топики одного телевизора — `iptv/<tv_id>/…`: `set_channel`, `command`, `state` (retained),
`availability`, `channels`, `current_playlist`, `set_playlist`, `vod/play`, `notify` (плашка с текстом),
`suggest` (страница подборки), `tv/power_on`, `tv/launch`.
Полный список — в шапке `js/mqtt-bridge.js`. Для каждого телевизора плеер создаёт устройство в HA
(MQTT Discovery): `sensor.iptv_<tv_id>_playback` (атрибуты — всё о воспроизведении),
`sensor.iptv_<tv_id>_channel`, `select.iptv_<tv_id>_playlist`, громкость, кнопки.

## Как это устроено внутри

| Файл | Что делает |
|------|-----------|
| `server.js` | HTTP, страница аддона, MQTT, реестр телевизоров, питание и запуск приложения, запросы `iptv/request` |
| `build.js` | загрузка и разбор M3U/XMLTV, сопоставление каналов, сборка плейлистов |
| `archive.js` | проверка реального архива у каналов (запрос сегментов) |
| `vod.js` | поиск фильмов по источникам, карточка, постеры |
| `plugins.js` | плагины-источники: установка со страницы, настройки, раздача копий телевизорам |
| `sandbox.js`, `plugin-host.js` | песочница плагинов: отдельный процесс без доступа к файлам и токену Supervisor |
| `pairing.js` | привязка телевизора по коду |
| `mqtt-proxy.js` | MQTT телевизоров через аддон |
| `tmdb.js`, `kinopoisk.js` | рейтинги, жанры, описания, рецензии |
| `favorites.js` | общее избранное |
| `guide.js` | поиск по программе передач, напоминания |
| `parental.js` | PIN, группы, ограничения по телевизорам |
| `card-data.js` | данные и файлы карточки в `/homeassistant/www/tizen-iptv` |
| `shared/` | копии парсеров из `js/` — каналы на Pi и на TV должны сопоставляться одинаково |

> **Про `shared/`.** Это копии общих файлов плеера: парсеры, поиск каналов, реестр и плагины
> источников фильмов (`vod-sources/`), переводы (`lang/`). Логика не дублируется: файлы копирует `deploy.ps1`.
> При ручной установке скопируйте их сами после правок в `js/`.

Проверить поиск каналов по «голосовому» имени можно без HA:

## Если что-то не так

| Симптом | Что проверить |
|---------|---------------|
| `/status` не открывается | аддон не запущен; порт 8765 занят (сменить в разделе «Сеть» аддона и в настройках телевизора) |
| В `/status` есть `lastError` с `HTTP 4xx/5xx` | недоступен плейлист (истёк токен) или источник EPG — откройте ссылку из ошибки в браузере |
| `matchedChannels` резко упал | провайдер переименовал каналы — смотреть `unmatched`, привязать вручную на странице аддона |
| У канала есть логотип, но нет программы | пробел источника: у части каналов в it999 передач нет вообще. Поможет только второй источник в `epg_urls` |
| Телевизор пишет, что аддон недоступен | в журнале аддона нет обращений от TV — проверьте адрес аддона в настройках телевизора и что TV и Pi в одной сети |
| Карточка старая | перезагрузить страницу HA; старая версия карточки шлёт старые команды |
| Поиск фильмов в карточке молчит | подписка MQTT доступна только администратору HA |
| У фильмов нет рейтинга | не задан ключ или кончилась дневная квота — `/status`, поле `kinopoisk` |
| Нет кнопки «Рецензии» | не задан `kinopoisk_key` или у фильма рецензий нет |
| Новый источник фильмов не виден | `/status` → `vod_sources`: есть ли он и нет ли у него `error` ([vod-plugins.md](vod-plugins.md)) |
| Аддон остановился после добавления большого источника EPG | не хватило памяти — уберите источник или уменьшите число источников; журнал покажет причину |
