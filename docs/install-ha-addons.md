# Шаг 1. Home Assistant: брокер MQTT, телевизор и аддон IPTV

🇬🇧 [English](en/install-ha-addons.md)

После этого шага у вас будет работать аддон «AssisTV»: он скачивает ваш плейлист и программу
передач и готовит их для телевизоров. Приложение на телевизор ставится на следующем шаге —
[install-tv.md](install-tv.md).

Названия пунктов меню даны для Home Assistant 2026.9 на русском языке. В более старых версиях
«Приложения» назывались «Дополнения» (Add-ons).

## Что нужно заранее

- **Home Assistant OS** (или Supervised) — там, где в меню «Настройки» есть пункт **«Приложения»**.
  Проверено на Raspberry Pi 4 (4 ГБ). Подойдут также Pi 5, мини-ПК, виртуальная машина.
- Телевизор и Home Assistant — в одной домашней сети.
- Ссылка на ваш **плейлист M3U** (её даёт IPTV-провайдер) и ссылка на **программу передач XMLTV**
  (обычно тоже у провайдера; например, `https://epg.it999.ru/epg.xml.gz`).
- Узнайте **IP-адрес Home Assistant**: Настройки → Система → Сеть (например, `192.168.1.10`).
  Дальше в инструкции он обозначен как `<IP HA>`.
- Узнайте **IP-адрес телевизора**: на телевизоре Настройки → Общие → Сеть → Состояние сети → Настройки IP.
  Лучше закрепить за телевизором постоянный адрес в роутере.

## 1.1. Брокер MQTT (Mosquitto)

Через него Home Assistant передаёт команды телевизорам. Если MQTT у вас уже есть — пропустите.

1. **Настройки → Приложения → Установить приложения** (кнопка внизу справа).
2. Найдите **Mosquitto broker** → **Установить** → **Запустить**. Включите «Запускать при загрузке».
3. Home Assistant сам предложит интеграцию **MQTT**: Настройки → Устройства и службы → в разделе
   «Обнаружено» нажмите **Настроить** у MQTT → **Отправить**.
4. Проверьте, что у Mosquitto открыт порт WebSocket: Mosquitto broker → вкладка **«Конфигурация»** →
   раздел **«Сеть»**: у строки **1884/tcp** должно стоять `1884`. Именно по нему подключается телевизор.
   В стандартном Mosquitto он включён сразу, настраивать больше ничего не надо.

## 1.2. Интеграция Samsung Smart TV (для включения телевизора)

Нужна, чтобы Home Assistant мог **включать** телевизор (карточкой или голосом). Без неё плеер работает,
но включать телевизор придётся пультом.

1. Телевизор включён. **Настройки → Устройства и службы → Добавить интеграцию** → найдите
   **Samsung Smart TV** → введите IP-адрес телевизора.
2. На экране телевизора появится запрос доступа — нажмите пультом **«Разрешить»**.
3. Появятся сущности вида `media_player.<название>` и `remote.<название>`. Они пригодятся в шаге 1.5.

> Интеграция **SmartThings** для этого не подходит — нужна именно **Samsung Smart TV** (локальная).

## 1.3. Установка аддона «AssisTV»

Выберите один из способов.

### Способ А — из магазина приложений

Самое простое — кнопка (откроет ваш Home Assistant и предложит добавить репозиторий,
дальше сразу пункт 3):

[![Add the repository to my Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Findoor25%2FAssisTV)

Или вручную:

1. **Настройки → Приложения → Установить приложения** → меню **⋮** вверху справа → **Репозитории**.
2. Вставьте адрес `https://github.com/indoor25/AssisTV` → **Добавить** → **Закрыть**.
3. Обновите страницу (⋮ → «Проверить наличие обновлений»), найдите **AssisTV** → **Установить**.
   Первая установка занимает несколько минут: аддон собирается прямо на вашем сервере.

> Пока репозиторий на GitHub закрытый (private), Home Assistant не сможет его скачать —
> используйте способ Б.

### Способ Б — скопировать папку (работает всегда)

1. **Скачайте проект**: на странице репозитория на GitHub кнопка **Code → Download ZIP**,
   распакуйте архив. (Или `git clone https://github.com/indoor25/AssisTV.git`.)
2. Поставьте приложение **Samba share**: Настройки → Приложения → Установить приложения → Samba share →
   **Установить**. На вкладке «Конфигурация» задайте имя пользователя и пароль → Сохранить → **Запустить**.
3. На компьютере откройте сетевую папку:
   - Windows: в адресной строке Проводника `\\<IP HA>\addons`;
   - macOS: Finder → Переход → Подключение к серверу → `smb://<IP HA>/addons`.

   Введите логин и пароль из шага 2.
4. Скопируйте туда из распакованного проекта папку **`ha-addon/epg_builder`** целиком.
   Должно получиться `addons/epg_builder/config.yaml`.
5. В Home Assistant: **Настройки → Приложения → Установить приложения** → **⋮** →
   **Проверить наличие обновлений**. Вверху появится раздел **Local apps** с **AssisTV** →
   откройте → **Установить** (несколько минут).

### Способ В — одной командой с компьютера (для разработчиков)

Если вы правите код аддона, удобнее скрипт `ha-addon/deploy.ps1` (PowerShell 7): он копирует аддон
по SSH и сам устанавливает или обновляет его. Нужен аддон **Terminal & SSH** с ключом:

1. Создайте ключ: `ssh-keygen -t ed25519 -f $env:USERPROFILE\.ssh\ha_pi_ed25519 -N '""'`,
   покажите его: `Get-Content $env:USERPROFILE\.ssh\ha_pi_ed25519.pub`.
2. Terminal & SSH → «Конфигурация»: строку ключа — в `authorized_keys`; в разделе «Сеть» — порт **2222**
   (без порта SSH-сервер не запускается). Сохраните, перезапустите.
3. Из папки проекта: `.\ha-addon\deploy.ps1 -PiHost <IP HA>`.

## 1.4. Настройка аддона: ваши плейлисты и программа передач

1. Откройте **AssisTV** → вкладка **«Конфигурация»**.
2. **playlists** — список плейлистов, у каждого название и ссылка:
   - обычный плейлист каналов: `name: Телевидение`, `url: http://…/playlist.m3u8`;
   - фильмы и сериалы подключаются плагинами: после запуска аддона — панель AssisTV → «Плагины»
     ([vod-plugins.md](vod-plugins.md)).

   Примеры с `example.com` удалите или замените своими.
3. **epg_urls** — ссылки на программу передач (одна или несколько; выше в списке — важнее).
4. По желанию — **tmdb_key** и **kinopoisk_key**: бесплатные ключи, с ними у фильмов появятся рейтинги,
   жанры, описания и рецензии зрителей. Где их взять — в [addon-iptv.md](addon-iptv.md#рейтинги-и-рецензии).
   Можно добавить и позже.
5. Остальное можно не трогать (что это — в [addon-iptv.md](addon-iptv.md)).
6. **Сохранить**. На вкладке «Информация» включите **«Запускать при загрузке»**,
   **«Показывать на боковой панели»** и нажмите **«Запустить»**.

Первая сборка идёт примерно полминуты. Посмотреть, как она прошла:

- вкладка **«Журнал»** аддона — в конце должно быть что-то вроде
  `готово: совпало 1925/1977 каналов …`;
- или в браузере `http://<IP HA>:8765/status`.

## 1.5. Страница аддона: телевизоры

В боковом меню Home Assistant появился пункт **AssisTV**. Там:

- **Телевизоры** — появятся сами, когда плеер на них запустится первый раз (следующий шаг).
  Для каждого задайте понятное **название** («Телевизор в гостиной») и выберите **remote** и
  **media_player** из интеграции Samsung Smart TV (шаг 1.2) — без них не будет включения телевизора.
- **Комната.** Телевизор появится в Home Assistant как устройство «IPTV <название>». Укажите для него
  пространство (комнату): Настройки → Устройства и службы → Устройства → «IPTV …» → ✏️ → «Пространство».
  По комнате работают команды вроде «включи Первый канал в спальне».
- **Плейлисты** — что загружено и когда.
- **«+ Сопоставить канал»** — если у какого-то канала нет программы или она чужая.
- **Родительский контроль** — PIN и защищённые группы.

Подробно — [addon-iptv.md](addon-iptv.md).

## Если что-то не так

| Что видно | Что сделать |
|-----------|-------------|
| Аддона нет в «Local apps» | папка скопирована не туда: должно быть `addons/epg_builder/config.yaml`, а не `addons/ha-addon/epg_builder/…`; ⋮ → «Проверить наличие обновлений» |
| Ошибка при установке | нет интернета у сервера HA (скачивается образ Node.js); попробуйте ещё раз |
| `http://<IP HA>:8765/status` не открывается | аддон не запущен — вкладка «Журнал» покажет почему |
| В журнале `HTTP 401/403/404` у плейлиста | ссылка на плейлист неверная или токен истёк — откройте её в браузере |
| Совпало мало каналов | программа передач не та или каналы называются иначе — сопоставьте вручную на странице аддона |
| `MQTT: нет данных для подключения` | не установлен или не запущен Mosquitto broker (шаг 1.1) |
| Страница аддона «только просмотр» | настройки меняются только через пункт **AssisTV** в боковом меню HA, а не по адресу `:8765` |
