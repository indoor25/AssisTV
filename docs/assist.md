# Шаг 4. Голос и чат: управление плеером через Assist

🇬🇧 [English](en/assist.md)

**Assist** — голосовой помощник Home Assistant. Если к нему подключён ИИ (Google Gemini, OpenAI,
Anthropic Claude, DeepSeek, локальная Ollama и др.), ему можно писать в чат или говорить обычными словами:
«включи Первый канал в спальне», «что сейчас идёт?», «включи Интерстеллар в 4К», «какой рейтинг у Дюны?»,
«найди мне фильмы на основе моего избранного», «выключи телевизор через полчаса».
Микрофон не обязателен — писать можно в чат Assist в приложении или в браузере.

Чтобы ИИ мог управлять плеером, в Home Assistant добавляются несколько **скриптов** — это его «кнопки».
Каждый скрипт снабжён описанием, по которому ИИ сам понимает, когда и как его вызывать.

Перед этим шагом должны работать аддон ([шаг 1](install-ha-addons.md)) и плеер на телевизоре
([шаг 2](install-tv.md)). Скрипты из репозитория рассчитаны на свежий аддон — **2.17.1** или новее
(Настройки → Приложения → AssisTV — номер версии вверху) и плеер **1.1.0** или новее
(на телевизоре: Настройки → «Этот телевизор»). Со старым плеером всё работает, кроме страницы
подборки на экране.

## 4.1. ИИ-помощник в Home Assistant (если ещё нет)

На примере Google Gemini (у Google есть бесплатный тариф):

1. Получите ключ API: [aistudio.google.com](https://aistudio.google.com/apikey) → **Create API key**.
2. **Настройки → Устройства и службы → Добавить интеграцию** → **Google Generative AI** → вставьте ключ.
3. Откройте интеграцию → у агента разговора нажмите ⚙️ (настроить) → в поле
   **«Управление Home Assistant»** (Control Home Assistant) выберите **Assist** → **Отправить**.
   **Без этого ИИ только разговаривает и ничего не умеет включать.**
4. **Настройки → Голосовые ассистенты** → вкладка **«Ассистенты»** → откройте своего ассистента
   (или «Добавить ассистента») → **Агент разговора** — Google Generative AI, язык — русский → **Обновить**.
   Поставьте этого ассистента предпочтительным (⋮ → «Сделать предпочтительным»).

С OpenAI, Anthropic и другими — то же самое, отличается только интеграция на шаге 2.

## 4.2. Добавьте скрипты

Скрипты лежат в проекте в файле [`ha-config/iptv-assist-scripts.yaml`](../ha-config/iptv-assist-scripts.yaml).

1. Поставьте приложение **File editor**: Настройки → Приложения → Установить приложения → File editor →
   **Установить** → **Запустить**, включите «Показывать на боковой панели».
2. Откройте **File editor** в боковом меню → значок папки вверху слева → файл **`scripts.yaml`**.
3. Если файл пустой (или в нём только `{}` / `[]`) — вставьте туда **всё** содержимое
   `iptv-assist-scripts.yaml` вместо старого текста. Если в нём уже есть ваши скрипты — вставьте
   содержимое **в конец** файла, с новой строки.
4. Сохраните (значок дискеты вверху).
5. **Инструменты разработчика → YAML** → в разделе «Перезагрузка конфигурации YAML» нажмите **Скрипты**.
6. Проверьте: **Настройки → Автоматизации и сцены → Скрипты** — появились скрипты «IPTV: …» (их 13).

> **Обновляете со старой версии?** Удалите из `scripts.yaml` прежние скрипты IPTV (всё от `iptv_zapros:`
> до конца блока IPTV) и вставьте новые целиком, затем перезагрузите скрипты и **откройте доступ новым**
> (шаг 4.3). Забытый шаг 4.3 — самая частая причина ответа «я этого не умею».

Названия и описания скриптов — по-английски: так ИИ понимает их, на каком бы языке вы ни говорили,
и отвечает на вашем языке. Готовые фразы в ответах (`message`) аддон пишет на своём языке — опция
`language` аддона, по умолчанию язык Home Assistant.

| Скрипт | Что делает |
|--------|-----------|
| IPTV: switch TV channel | включить канал по названию, на нужном телевизоре; «с начала» — передача из архива |
| IPTV: play a movie or series | найти фильм во всех источниках и включить; качество («в 4К»); номер из подборки на экране |
| IPTV: find a movie | только найти, ничего не включая |
| IPTV: movie rating and description | рейтинг Кинопоиска и TMDB, жанры, описание; есть ли фильм у вас |
| IPTV: add a movie to favourites | добавить в избранное: то, что идёт, или по названию |
| IPTV: list favourite movies | что в избранном (и что уже смотрели) |
| IPTV: suggest movies on the TV | показать на телевизоре подборку страницей с постерами; «ещё варианты» |
| IPTV: player control | пауза, продолжить, стоп, следующий/предыдущий канал, громкость, звук, открыть плеер, выключить телевизор, передача с начала, прямой эфир, перемотка, таймер сна |
| IPTV: what is on now | канал, передача, до скольки, громкость |
| IPTV: TV guide | программа канала на сутки: «что дальше», «во сколько новости на …» |
| IPTV: find a programme in the TV guide | поиск передачи по всем каналам на несколько дней: «когда сегодня футбол?» |
| IPTV: what to watch tonight | подборка на вечер по каналам, которые у вас смотрят: «что посмотреть сегодня вечером?» |
| IPTV: move playback to another TV | продолжить на другом телевизоре с того же места: «перенеси в спальню» |
| IPTV: programme reminder | напомнить о передаче за 5 минут до начала, показать и убрать напоминания |
| IPTV: add-on request (internal) | через него работают остальные; ИИ его не показывайте |

## 4.3. Откройте ИИ доступ к скриптам

1. **Настройки → Голосовые ассистенты** → вкладка **«Доступ к объектам»** → кнопка **«+ Открыть доступ»**.
2. Отметьте все скрипты **IPTV: …**, кроме «add-on request (internal)» → **Открыть доступ**.

## 4.4. Проверьте

Откройте Assist: значок 💬 вверху справа на любой панели Home Assistant (в приложении на телефоне — тоже).
Напишите:

- «что сейчас идёт по телевизору?»
- «включи Первый канал в спальне»
- «сделай потише на 3»
- «найди фильм Матрица», затем «включи первую»
- «какой рейтинг у фильма Интерстеллар?»
- «добавь Интерстеллар в избранное»
- «найди мне фильмы на основе моего избранного» — на телевизоре должна появиться страница с постерами;
  затем «включи второй» или «ещё варианты»

Больше примеров — в [usage.md](usage.md#голос-и-чат-assist).

### Как работает подборка по избранному

Здесь ИИ и аддон делят работу:

1. ИИ вызывает «list favourite movies» и получает ваше избранное, список просмотренного и то, что
   недавно уже предлагал.
2. ИИ **сам**, по своим знаниям о кино, придумывает 12–15 похожих названий с годами.
3. Скрипт «suggest movies on the TV» отдаёт их аддону. Аддон проверяет каждое: есть ли у источников
   фильмов, не в избранном ли оно, не смотрели ли его. Что прошло проверку — уходит на телевизор
   страницей с постерами, рейтингом и описанием.
4. Вы выбираете пультом или говорите номер — ИИ вызывает «play a movie or series» с этим номером.

Поэтому качество подборки зависит от модели: чем лучше она знает кино, тем точнее попадание.
Аддон гарантирует только одно — всё, что на экране, действительно можно включить.

Фильм считается просмотренным, если шёл на телевизоре 10 минут; такие больше не предлагаются.
На «ещё варианты» не повторяется и то, что показывали за последние 6 часов.

### Чтобы телевизор не мешал слушать

Если у вас голосовая колонка рядом с телевизором, микрофон слышит и его. В
[`ha-config/iptv-voice-duck.yaml`](../ha-config/iptv-voice-duck.yaml) — готовая автоматизация: пока
колонка слушает команду, звук телевизора выключается, потом возвращается.

### Напоминание о передаче голосом

За 5 минут до начала аддон показывает плашку на телевизорах, где запущен плеер (**OK** на пульте включит
канал), и публикует в MQTT событие `iptv/reminder`:
`{title, channel, start, start_time, minutes, message, tvs}`. Чтобы напоминание ещё и прозвучало,
добавьте автоматизацию с триггером MQTT на этот топик и действием, которое произносит `message` вашим
способом (`tts.speak`, `assist_satellite.announce`, уведомление на телефон):

```yaml
- alias: "IPTV: programme reminder aloud"
  triggers:
    - trigger: mqtt
      topic: iptv/reminder
  actions:
    - action: assist_satellite.announce
      target:
        entity_id: assist_satellite.living_room
      data:
        message: "{{ trigger.payload_json.message }}"
```

Свой текст на экран телевизора можно вывести и из любой автоматизации: опубликуйте
`{"text": "…", "channel": "…", "seconds": 30}` в `iptv/<tv_id>/notify` (channel и seconds — по желанию).

```yaml
# пример: стиральная машина закончила — сказать об этом на экране телевизора в гостиной
actions:
  - action: mqtt.publish
    data:
      topic: iptv/qe55qn85c_xxxx/notify
      payload: '{"text": "Стирка закончена", "seconds": 20}'
```

Как ИИ понимает, какой телевизор: по названию телевизора на странице AssisTV или по комнате (пространству)
его устройства «IPTV …» в Home Assistant. Если комната не названа и плеер работает на одном
телевизоре — туда. Если работает на нескольких — ИИ переспросит. Если не работает ни на одном —
спросит, на каком включить.

## Если что-то не так

| Что видно | Что сделать |
|-----------|-------------|
| ИИ отвечает «не могу управлять устройствами» или просто болтает | шаг 4.1, п. 3: «Управление Home Assistant» — Assist; и шаг 4.3 |
| ИИ не видит скрипты | шаг 4.3 — скрипты не открыты для Assist |
| «Не могу показать подборку», «не умею добавлять в избранное» | добавлены новые скрипты, но им не открыт доступ (шаг 4.3) |
| Подборка называется голосом, но страницы на телевизоре нет | плеер старее 1.1.0 — обновите ([install-tv.md](install-tv.md)); или не понятно, на каком телевизоре — назовите комнату |
| В подборке мало фильмов | у источников нашлось не всё, что придумал ИИ; скажите «ещё варианты» |
| Нет рейтингов и описаний | не заданы `tmdb_key` / `kinopoisk_key` в настройках аддона |
| ИИ зачитывает длинные списки | это его манера; допишите в инструкции ассистента «отвечай коротко, одной-двумя фразами» |
| Скриптов нет в списке | ошибка в `scripts.yaml` — Инструменты разработчика → YAML → «Проверить конфигурацию» покажет строку |
| «The IPTV add-on did not answer» (аддон не ответил) | аддон не запущен или старее 2.7.0; нет устройства «IPTV аддон» с датчиком `sensor.iptv_otvet` — аддон не подключён к MQTT |
| «Не знаю телевизор …» | задайте телевизору название на странице AssisTV или пространство устройству «IPTV …» |
| Канал «защищён родительским контролем» | так задумано: голосом и через чат защищённые каналы не включаются |
| Включение выключенного телевизора не срабатывает | у телевизора на странице AssisTV не выбраны remote и media_player |

## Как это устроено (для любопытных)

```
Assist (ИИ) → script.iptv_tv_channel / iptv_play_movie / iptv_suggest_movies / …
            → script.iptv_zapros → MQTT iptv/request → аддон IPTV → телевизор
                                                                ← sensor.iptv_otvet ← MQTT iptv/request/result
```

Служебный скрипт публикует запрос с уникальным `request_id` и ждёт, пока этот `request_id` появится
в атрибутах датчика `sensor.iptv_otvet` (его создаёт аддон; атрибуты — весь ответ). Ответ скрипта —
словарь с полем `message`: его ИИ и пересказывает. Аддон сам выбирает телевизор, при необходимости
включает его и запускает плеер. Формат запросов — в [addon-iptv.md](addon-iptv.md#управление-из-автоматизаций-и-голосом).
